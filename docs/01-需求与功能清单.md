# MyBlog 需求与功能清单

个人博客系统：前台展示 + 访客互动 + 管理后台，前后端分离。单管理员模式。

## 技术栈（已定，执行期间不得更换）

- 后端 `server/`：Go 1.27 + Gin + GORM + SQLite（默认，纯 Go 驱动）/ MySQL（可选）
- 前台 `web/`：Vue 3 + TypeScript + Vite + Pinia + Vue Router + axios + markdown-it + highlight.js
- 管理端 `admin/`：Vue 3 + TypeScript + Vite + Ant Design Vue 4 + Pinia + axios + md-editor-v3 + ECharts
- 认证：JWT（Bearer），密码 bcrypt
- 界面语言：中文

## 前台功能（web/）

1. 首页文章列表：分页、封面、摘要、分类、标签、阅读量、发布时间；置顶文章优先
2. 文章详情：Markdown 渲染、代码高亮、目录 TOC、上一篇/下一篇、相关文章、点赞、阅读次数
3. 归档页：按年月分组的时间线
4. 分类页 / 标签页：全部列表 + 按分类/标签筛选文章
5. 搜索：标题/摘要/内容关键词
6. 自定义页面（如"关于"）
7. 友链页
8. 评论：游客评论（昵称/邮箱/网站选填）、楼中楼二级回复、审核通过后展示
9. 站点框架：导航、公告栏、热门文章、标签云、页脚（ICP/版权）
10. RSS 订阅（/rss）
11. 暗色模式（跟随系统 + 手动切换，记忆选择）
12. 移动端响应式

## 管理端功能（admin/）

1. 登录/登出、修改密码、个人资料（昵称/邮箱/头像）
2. 仪表盘：文章/草稿/计划发布/评论/浏览/点赞统计卡片、最近 7 天发布与评论趋势图、最近评论、计划发布
3. 文章管理：列表（关键词/状态/分类筛选，状态含定时发布）、Markdown 编辑器、封面（媒体库或外链）、多标签、草稿/发布/隐藏/定时发布（后端到点自动上线）、置顶、自动保存（防抖写服务器，本地兜底）、版本历史（变更说明/文本对比/一键恢复，恢复可撤销）、删除
4. 分类管理 CRUD（含文章数）
5. 标签管理 CRUD（含文章数）
6. 专题管理：CRUD、显隐/排序、成员文章排序（一文一专题）；前台专题列表/详情页、文章详情"第 X/N 篇"与专题内上下篇
7. 评论管理：全部/待审/通过/拒绝/垃圾/回收站筛选、批量通过/拒绝/标垃圾/删除、IP/邮箱/关键词黑名单、反垃圾规则（重复内容/链接过多/同昵称高频）、管理员回复、删除（可见 IP/邮箱）
8. 友链管理 CRUD（显示/隐藏、排序）
9. 页面管理 CRUD（关于等自定义页面）
10. 重定向管理：301/302 规则 CRUD、环检测；slug 变更自动 301（可关）
11. 媒体库：图片上传、网格/列表双视图、删除
12. 数据：访问分析（PV/UV/趋势/热门文章/来源/设备/浏览器/OS，今日与 7/30/90 天）、重定向入口
13. 系统：系统设置、站点健康（版本/DB 状态/计数/最近备份）、备份（数据库/全站 zip，下载/删除，MySQL 模式明确提示）、全站导出/导入（预览 + 跳过/更新策略）、操作日志（审计，IP 哈希化）
14. 通知中心：新待审评论/垃圾评论/定时发布完成/备份事件，铃铛未读数（轮询）

## 非功能要求

- API 统一响应 `{code, message, data}`，唯一契约见 `docs/contracts/api.md`
- 评论接口同 IP 60 秒限流 1 次
- LIKE 查询转义 `%`、`_`、`\`
- 上传仅允许图片，单文件 ≤ 10MB
- 初始账号 `admin / admin123`（登录后可修改）

## 明确不做（出范围）

多用户注册/RBAC 多角色、第三方登录、邮件通知、对象存储/CDN、全文搜索引擎（用 LIKE）、文章密码保护、国际化。
