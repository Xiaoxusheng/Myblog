# 前台 UI 改版二期设计规范——静奢编辑风(Quiet Luxury Editorial)

> 版本:v2.0 · 对应改版轮次 V7–V11 · 日期:2026-09-20
> 前置:docs/04-前台UI设计规范.md(V1–V6 编辑部式极简)已完成,本轮在其基础上做**二期升级**,不推倒重来。

---

## 0. 一句话定位

在一期「编辑部式极简」的骨架上,注入 2025 年主流审美中已验证的高级感杠杆:**衬线大标题(Serif Display)、纸面颗粒、报头化导航、结构化页脚、阅读排版精修**。整体气质从「干净的极简」升级为「有人手打磨痕迹的静奢」。

## 1. 调研依据(GitHub 主流博客审美)

| 来源 | 关键特征 | 本轮吸收 |
|---|---|---|
| hugo-PaperMod(11k★) | 灰度极简、单列、mono meta、archives 时间轴 | 已在一期落地,保持 |
| AstroPaper(3.5k★) | 双主题、可折叠 TOC、预定义配色、无障碍实测 | 已有;暗色与焦点态继续精修 |
| antfu.me / leerob.io | 内容即界面、大标题、克制留白 | Hero 大字升级衬线 + 句点装饰 |
| Medium / Substack 系 | 衬线标题 + 无衬线正文的双字族对比 | **本轮核心:display 衬线层** |
| 2025 排版趋势(Awwwards/Blaze Type) | editorial serif 回潮,衬线=高级感最大杠杆 | 见 §3 排版 |
| overreacted.io 等个人博客 | 标题尾部 accent 句点、签名式细节 | Hero 与 404 采用 |

**共同结论**:主流高星主题全部是 Neutral ≈ 90%+ 的灰度纸面 + 唯一强调色的克制体系;「高级感」差异集中在**字体层级对比**与**微工艺细节**,而不是颜色与组件。

## 2. 改 vs 不改

**改**:设计 Token(新增 display 衬线字族、颗粒纹理、字号刻度)、Hero/导航/页脚、文章详情排版、各列表页标题层级、暗色模式层次、微交互细节。

**不改(红线)**:框架栈(Vue3+Vite+原生 CSS)、路由与页面清单、API 与业务逻辑、SEO/埋点/无障碍语义、v-reveal 动效机制、类名体系(尽量沿用一期类名做样式升级,不大规模重命名)。

## 3. 排版系统(本轮最大变更)

### 3.1 双字族体系

- 新增 `--font-display`(衬线栈),仅用于 **display 级别的大字号场景**:
  `Georgia, 'Times New Roman', 'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', SimSun, serif`
- 通过 `@font-face` 尝试加载 Noto Serif SC(`font-display: swap`,来源 fonts.loli.net 镜像);
  加载失败时回落系统宋体/Georgia,不阻塞渲染、不产生布局跳动(仅标题,面积小)。
- 正文、导航、列表行标题、meta **维持 sans/mono**,不衬线化——衬线只出现在大字号,避免小字号宋体的低质渲染。

### 3.2 衬线使用白名单

| 位置 | 规格 |
|---|---|
| Hero 站名 | `--fs-display`(clamp 36–52px)/ 620 / -0.01em / 尾部 accent 句点 |
| 文章详情标题 | clamp(30–40px)/ 620 / -0.01em |
| 列表页大标题(page-heading) | 30px / 620 |
| Featured 标题 | clamp(22–26px)/ 620 |
| 页脚品牌字 | 15px / 620(报头感) |
| 404 大字 | 衬线 + accent 句点 |

### 3.3 字号刻度微调

`--fs-display` 由 clamp(32,5vw,44) 上调至 **clamp(36px, 5vw, 52px)**;新增标题通用规则 `text-wrap: balance`,正文段落 `text-wrap: pretty`。

## 4. 纸面颗粒(Grain)

- `body::after` 全屏 fixed 覆盖层,SVG feTurbulence 噪点,`opacity: 0.022`(dark 0.03),`pointer-events: none`,`z-index` 低于一切交互层。
- 作用:消除大面积纯色的「塑料感」,还原纸张肌理。禁用条件:`prefers-reduced-transparency` 时移除。

## 5. 各区域改造要点

### 5.1 导航(报头化 Masthead)

- 品牌字换 `--font-display` 衬线 17px,序齿如刊物报头;logo 图不做变化。
- 导航项、搜索、主题切换结构不动;active 下划线保持。
- 高度 60px、blur、滚动 hairline 全部保持。

### 5.2 首页 Hero

- 站名衬线大字 + **尾部 accent 句点**(用 `::after` 伪元素,不写入数据)。
- 描述行 16px `--text-2`;统计行保持 mono 大写。
- 下方 hairline 分隔保持;featured 与列表行结构不动,featured 标题衬线化。

### 5.3 页脚(结构化三区)

由「居中两行」升级为编辑部式三区:

```
┌────────────────────────────────────────────┐
│ 品牌字 + 一句简介      |  导航列  |  订阅列  │
│ (左区,占位最大)      | 首页/归档…| RSS/地图 │
├────────────────────────────────────────────┤
│ 版权 · ICP · Powered by(居中/左,13px,m3)│
└────────────────────────────────────────────┘
```

- 上区桌面三列(左 2fr / 右两列各 1fr),移动端纵向堆叠;链接 hover 下划线动画沿用。
- 下区一行 meta:`© 年份 站名 · ICP · Powered by MyBlog`,ICP 链接跳工信部。

### 5.4 文章详情页

- 标题衬线化(§3.2);meta 行、封面、TOC、上下篇结构不动。
- markdown.css 精修:
  - 引用块:左侧 2px hairline + 衬线 17px 文字 + 引号色 `--text-3`;
  - `hr` 升级为居中短横(60px hairline),去全长分隔;
  - 图片:radius-md + 1px `--border` 描边;`figcaption` mono 12px 居中;
  - 行内代码底色随主题已分离,保持;
  - 标题锚点 hover 显现 `#`(若已有则只调色)。
- 阅读进度条、点赞、评论结构不动。

### 5.5 其余页面(Archives/Categories/Tags/Series/Search/Links/404)

- 全部 page-heading 衬线化;年份、计数、meta 保持 mono。
- 404:衬线大字「404」+ accent 句点 + 一句引导;按钮用现有 `.btn-ghost`。

### 5.6 暗色模式

- 层次保持一期四层分离;仅随 Token 自动继承,不单独重设计。
- 衬线在暗色下字号不变、weight 降至 600(宋体暗色加粗易糊)。
- 颗粒透明度 0.03。

## 6. 微交互与工艺细节

1. 标题统一 `text-wrap: balance`;`letter-spacing` 衬线标题 -0.01em(中文不加负距)。
2. 列表行标题 hover:保持变色方案,新增 `transition` 时长 0.18s。
3. `:focus-visible` ring 保持;`::selection` 保持。
4. 封面 hover scale 1.03 保持;featured 封面 hover 加 1px 边框色加深。
5. 所有动效 ≤ 400ms、ease-out;`prefers-reduced-motion` 已全局覆盖。

## 8. 出口条件

1. 无模板感:无渐变堆砌、无卡堆、无大投影;accent 仍 ≈ 5%。
2. 衬线只出现在 display 白名单场景,小字号无宋体。
3. dark 模式逐页核对:四层背景分离、文字对比达标。
4. 375px 宽度无横向滚动、触控目标 ≥ 40px。
5. Loading(Skeleton)/ Empty / Error 三态在首页与列表页可用。
6. `npm run build` 零错误;功能回归:导航/搜索/分页/主题切换/评论/TOC 正常。
