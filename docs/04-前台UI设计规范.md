# 04 · 前台 UI 设计规范（现代编辑部式极简改版）

> 版本：v1.0（2026-09-20）
> 适用范围：`web/` 前台全部页面与通用组件。**不涉及** `admin/` 管理端、`server/` 后端、API 契约、路由结构与业务逻辑——本规范是纯视觉/排版/交互层改版，不删功能、不改接口、不改路由。

---

## 1. 背景与目标

现有前台已具备完整的 Token 体系与克制的交互，但整体观感仍是「通用 CMS 模板」：卡片堆叠（正文、列表、侧栏、上下篇、相关文章全部包卡）、品牌色使用频率偏高、hero 区模板感强（kicker + 柔光渐变 + 统计块）、信息层级靠"卡片+阴影+边框"三件套而非排版本身。

本次改版目标：**让内容成为界面，界面退到纸一样的背景里**——达到 AstroPaper / antfu.me / Vercel(Geist) 级别的"专业设计师手笔"质感：现代、简约、高级、耐看。

一句话定位：**现代编辑部式极简（Modern Editorial Minimal）**。

## 2. 调研结论：GitHub 主流博客审美基准（2025-09）

对 GitHub 高星博客主题与标杆个人站的调研结论：

| 参照 | 星标/地位 | 可借鉴要点 |
|---|---|---|
| [AstroPaper](https://github.com/satnaing/astro-paper)（Astro，3.5k+ ★） | Astro 第一极简主题 | 近单色 + 单 accent；单栏 768px 阅读列；列表是「标题+日期+标签」的编辑行而非图片卡；暗色一等公民 |
| [hugo-PaperMod](https://github.com/adityatelange/hugo-PaperMod) | Hugo 使用最广主题 | "刻意稀疏"让内容突出；日期等宽排列；归档即时间轴 |
| [antfu.me](https://github.com/antfu/antfu.me) | 设计工程师标杆个人站 | 排版即设计：灰阶层级 + 字重对比 + 大量留白；无卡片；hover 微反馈；暗色默认 |
| leerob.com / rauno.me | Vercel/Geist 审美圈 | hairline 边框分层（#e5e7eb 级）而非阴影；accent 极少出现 |

**共识（也是本规范的理论依据）：**

1. 高分主题清一色极简：limited colors, simple layout, nice spacing & typography。
2. 分层靠**背景亮度差 + hairline 边框**，几乎不用投影；卡片是例外不是常规。
3. Neutral ≈ 95%，Brand accent ≈ 5%——accent 只出现在：链接 hover、当前导航态、精选标记、focus ring。
4. 深色模式重新设计而非反色：近黑微暖（#111113 级），去饱和，层级靠亮度差。
5. 2025 趋势「evolved minimalism」：极简骨架 + 一处大胆表达（超大 display 标题 / mono 编辑感小字）。

## 3. 设计原则（改什么 / 不改什么）

**改：**
- 视觉语言：卡片体系 → 编辑部式排版体系（hairline 分隔、留白、字重、灰阶）。
- Token 全量重校：中性层、accent 使用策略、圆角、阴影、字距、动效刻度。
- 信息层级：列表 → 编辑行；侧栏 → 文字栏；正文 → 直接落在纸面。
- 暗色模式按新中性层重新校准。

**不改：**
- 框架与栈（Vue3 + Vite + 原生 CSS Token）、路由、页面清单、API、业务逻辑、SEO、埋点、无障碍结构。
- 所有既有功能：搜索、TOC、点赞、评论、Lightbox、主题切换、阅读进度、移动端目录抽屉等全部保留，只换皮。
- 类名尽量保留（`.card` 等通用类仍在，只是视觉降级），保证改动集中在样式层。

### 4.3 Token 使用策略

- **accent 出现位置白名单**（除此之外一律灰阶）：`a:hover` 链接变色、当前导航态、Featured kicker、侧栏热门前三编号、focus-visible ring、阅读进度条、点赞已赞态。
- chip 类标签默认**去底色**：改为 text-2 文字 + hover 变 accent（分类/标签皆如此）；仅「置顶」「已赞」保留 soft 底。
- 阴影仅用于浮层（popover、toast、抽屉、下拉）；内容层一律 hairline。

## 5. 排版规范

| 角色 | 规格 |
|---|---|
| Display（Hero/文章 H1） | `--fs-display` / 650 / line-height 1.25 / letter-spacing -0.015em（中文标题退化为 -0.005em 观感可接受） |
| 页面标题 | 22px / 600 |
| 文章列表标题 | 17px / 600 / line-height 1.5 |
| 正文阅读 | 17px / 1.85（≥640px），15.5px / 1.8（<640px） |
| Meta（日期/阅读数/标签） | 12.5–13px / text-3；**日期与统计用 `--font-mono` + `tabular-nums`** |
| 编辑感小标题（kicker/侧栏栏头） | 11.5px / 600 / mono 字体 / letter-spacing 0.14em / 大写 |
| 说明/空态 | 13.5px / text-3 |

中文排版注意：负字距只对拉丁密集标题生效，正文禁用负字距；中文字重对比主要靠 650 vs 400，不用 italic（中文斜体观感差，blockquote 不用斜体）。

## 6. 布局与栅格

- 容器 1120px，页边距 20px（移动）/ 24px（≥768px）。
- 首页/列表页：主列 + 280px 右栏，gap 48px（原 32px，拉开编辑感呼吸）。
- 文章页：主列 + 240px TOC 栏，gap 56px。
- 阅读列 720px；正文不再包卡片，直接落底色。
- Section 间距：首页 hero 下 40px；文章区块间 36–48px。

## 7. 组件规范

### 7.1 Header
- 高 60px，sticky + blur（backdrop-filter 12px），底部 1px hairline（scrolled 才出现，背景加深）。
- 品牌：站点名 16.5px / 650 / letter-spacing 0.2px；有 logo 时 24px 圆角 6。
- 导航：14px / text-2；hover 变 text-1；**active 态 = 文字 text-1 + 底部 2px accent 短线（宽 = 文字宽，圆角 1px，offset 底 14px）**，弃用胶囊底色。
- 搜索框 190px，surface-2 底、hairline、focus 变 surface + border-strong。
- 移动端（<768px）：隐藏 nav 与搜索，汉堡按钮展开全宽下拉面板（surface 底 + hairline 下边）。

### 7.2 文章列表行（首页/分类/标签/搜索，原 ArticleCard）
- **去卡片**：透明底、无边框，行间以 1px hairline `border-bottom` 分隔，行 padding 22px 0（移动 18px 0）。
- 行内布局：左主列（标题 17px/600 → 摘要 13.5px/1.75 两行 clamp → meta 行）+ 右封面 136×90、radius 8。
- 标题 hover：变 accent（去下划线动画，纯色变更克制）。
- meta 行：mono 日期 12.5px text-3 + 分类名（纯文字，hover accent）+ `#标签`（text-3）。阅读数/赞并入 meta 行尾部，tabular-nums。
- hover 整行：背景不变（编辑部式），仅标题/封面反馈（封面 img scale 1.03，0.4s ease-out-quart）。
- 置顶徽标：soft 底 + accent 字，12px，radius 999。

### 7.3 Featured（首页置顶）
- 保留左右结构，kicker 用 mono 大写「FEATURED」+ accent；标题 clamp(22px, 2.8vw, 26px)/650；封面 344px、radius-lg。
- 区块上下用 hairline 与普通列表分隔。

### 7.4 侧栏（去卡片 → 文字栏）
- 移除 `.side-card` 的底/边框/圆角；每个 section 间 28px + 顶部 hairline（首个无）。
- 栏头：mono 11.5px 大写 letter-spacing 0.14em / text-3（公告→「NOTICE」、热门→「TRENDING」、专题→「SERIES」、标签→「TAGS」）。
- 公告：左侧 2px accent 竖线 + 文字 13.5px text-2，无底色。
- 热门榜：mono 两位编号（01–05），前三 accent，其余 text-3；标题行 13.5px，hover accent；阅读数右对齐 mono text-3。
- 标签云：纯文字 chip（无底），hover accent。
- sticky 顶距 header + 24px。

### 7.5 文章详情
- 标题区：分类 chip（纯文字）→ H1 display → meta 行（mono 日期 + 更新/阅读/时长，text-3，分隔点弱化）。
- 封面：radius-lg + hairline，max-height 430px。
- 正文容器：**去 `.card` 包裹**——透明底无边框，上下与 header/footer 区用 36px 留白 + hairline 分隔；内边距归零，`--reading-width` 限宽。
- Markdown 排版（markdown.css 同步升级）：
  - 正文 17px/1.85；h2 上 2.2em 下 0.7em + hairline 底边；h3 18px。
  - 行内代码：code-bg 底 + radius 5 + 0.87em，无边框（更轻）。
  - 代码块：code-bg + hairline + radius-md；语言标签与复制按钮保留；pre 14px/1.75。
  - blockquote：左 2px border-strong 竖线 + text-2，**去底色**（编辑部引用感）。
  - 表格：去竖线，仅横向 hairline（表头下 2px border-strong），th 用 surface-2 无底、mono 小字距？——th 保持 600/13px。
  - 图片 radius-md + hairline。
  - 链接：accent 色，hover 下划线。
- 上下篇：两列区块，顶部 hairline；label 12px text-3；标题 14.5px/500 hover accent；占位态弱化。专题上下篇同构。
- 相关文章：三列，无卡，顶部 hairline + mono 栏头「RELATED」；条目 = 标题（hover accent）+ 日期 mono。
- 点赞：胶囊按钮保留，高度 38px，hairline 边框，已赞态 accent soft。
- TOC（桌面右栏）：去卡无边框；条目 13.5px，hover text-1，active = accent + 左侧 2px 竖线；层3 缩进 12px。
- 阅读进度条：2px，accent。

### 7.6 Footer
- 两行极简居中：版权行 + 链接行（RSS/Sitemap/Power）。顶部 hairline；背景与页面同色（去 surface 差异）。
- 链接 hover accent；13px text-3；上 padding 28px 下 40px。

### 7.7 通用件
- `.btn`：高 36px，radius 6；ghost 态 hairline。`.chip` 去底（见 4.3）。`.card` 类保留但默认透明底无边框（逐步废弃），新布局不再依赖。
- Skeleton：surface-2 底 + 微光 shimmer（dark 下 0.06 白），radius 6。
- Pagination：数字 mono，当前页 text-1 + 下方 2px accent 短线，其余 text-3，hover text-1。
- EmptyState：居中，mono 栏头式小标题 + 说明 text-3；ErrorState 保留重试按钮。
- Toast / Lightbox / BackTop：阴影用 shadow-md，其余对齐新 token。

## 8. 页面级规格

| 页面 | 改法要点 |
|---|---|
| HomeView | Hero：去 kicker 与柔光渐变 → 站点名 display 大字 + 一句描述（text-2，max 560px）+ mono 统计行（`N POSTS · N CATEGORIES · N TAGS` 大写字距）+ 下方 hairline；下接 Featured（如有）→ 编辑行列表 → Pagination；移动端发现区对齐新 token |
| ArchivesView | 年份 mono 大字分组 + 文章行（日期 mono 左对齐 + 标题），hairline 分隔，时间轴感 |
| CategoriesView / TagsView | 两列网格（≥640px），条目 = 名称 + mono 计数，hover accent，去卡 |
| CategoryPostsView / TagPostsView | 页头（名称 + mono 计数）+ 编辑行列表复用 7.2 |
| SeriesView / SeriesDetailView | 专题条目去卡：名称 + 篇数 mono + 描述一行，hairline 分隔；详情页专题头部加 mono 「SERIES」kicker |
| SearchView | 搜索头部（mono 耗时/计数）+ 编辑行列表复用 7.2；空态给关键词建议（保留现有逻辑） |
| LinksView | 去卡 → 三列（≥640px）纯文字链接卡：名称 + 一行描述 + hairline 分隔 |
| PageView | 复用正文排版（去卡） |
| NotFoundView | 居中大字 404（mono）+ 返回链接 |
| PostDetailView | 见 7.5 |

## 9. 暗色模式规范

- 按第 4.2 节全量替换；所有组件在 dark 下逐一核对：层级（bg < surface < surface-2 < popover 亮度递增）、hairline 可见但不刺眼、accent 提亮、代码高亮沿用 GitHub Dark 色板（现有 --hl-* 不动）。
- 切换无闪烁（现有 theme store 机制保留）。

## 10. 动效规范

- 保留现有刻度：hover 0.16s ease-out；进场 reveal 0.5s ease-out-quart（错峰 ≤275ms）；页面切换 0.22s。
- 删除项：无。新增项：无。原则——动效全部服务于反馈，不做装饰性动画。
