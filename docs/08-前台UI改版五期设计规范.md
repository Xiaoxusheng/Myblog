# 前台 UI 改版五期设计规范——全域一致 · 默认感清零(Zero Defaults)

> 版本:v1.0 · 对应改版轮次 V21–V25 · 日期:2026-09-20
> 前置:docs/07-前台UI改版四期设计规范.md(V17–V20)已完成并通过验收;本轮不推倒重来,做**第五期一致性扫荡**。

## 0. 一句话定位

一期立骨架、二期做好看、三期立工艺、四期收质感。五期解决的问题是「**不均匀**」:首页/详情/归档是精修区,分类/标签/友链/专题还是 hairline 毛坯;正文区缺标题锚点、外链标识、图片占位三件标配工艺;空态两套语言并存;JS 硬编码滚动偏移、闲置的 --fs token、死代码、翻页不回顶——这些「最后一层」不一致,是成熟产品与拼装产品的分水岭。五期目标:**让全站每个区域、每种状态、每个行为都像同一批人定稿的**。

## 2. 改 vs 不改

**改**:markdown.ts(heading_close 注入锚点、链接规则改外链判定)、markdown.css(header-anchor/ext-link/img 占位样式)、PostDetailView(封面比例)、CategoriesView/TagsView/LinksView/SeriesView/SeriesDetailView(hover 反馈)、EmptyState(compact 变体)、SiteSidebar/CommentSection(空态接入)、CommentForm(字数计数)、CommentItem(顶级评论去卡)、SiteHeader(移动菜单遮罩+双 hairline 修复)、HomeView(MobileDiscover 增公告)、usePagedList(统一回顶)、CategoryPostsView/TagPostsView/SearchView(URL page 参数)、main.css(--fs 归位/页级滚动条)、PostToc/PostDetailView(--header-offset 消费)、删除 SearchBox.vue。

## 4. 正文工艺补全(V21,markdown.ts + markdown.css + PostDetailView)

### 4.1 标题 hover 锚点(V21 旗舰件)

- **注入**:markdown.ts 新增 `heading_close` 规则——从 `tokens[idx-1]`(heading_open)取已生成的 id,在闭合标签前插入 `<a class="header-anchor" href="#<id>" aria-label="标题锚点">#</a>`。锚点在 inline 内容之外,标题选中复制、TOC 文本收集均不受影响(现 heading_open 规则零改动)。
- **样式**(markdown.css):
  ```css
  .markdown-body .header-anchor {
    float: left; margin-left: -1em; padding-right: 4px;
    color: var(--text-3); text-decoration: none; opacity: 0;
    transition: opacity var(--transition), color var(--transition);
  }
  .markdown-body h2:hover .header-anchor,
  .markdown-body h3:hover .header-anchor,
  .markdown-body h4:hover .header-anchor,
  .markdown-body .header-anchor:focus-visible { opacity: 1; }
  .markdown-body .header-anchor:hover { color: var(--brand); }
  ```
  负 margin 悬挂于正文列外左侧(编辑风页边),不占正文宽度;触屏无 hover,保持 opacity:0 但仍可被屏幕阅读器聚焦(可访问性兜底);打印样式下 opacity:0 隐藏。
- 作用域:h2–h4(h1 不出现在正文,跳转层级与 TOC 一致)。

### 4.2 外链识别与标识(缺陷修正 + 工艺)

- **行为修正**(markdown.ts renderMarkdown):现行 `html.replace(/<a\s+href=/g, '<a target="_blank" ...')` 对全部链接生效——站内相对链接(`/posts/xx`)、页内锚点(`#xx`)也被新窗口打开。改为仅对 `href="http(s)://` 开头的链接追加 `target="_blank" rel="noopener noreferrer"`,其余链接保持原样(站内链接由 SPA 接管、锚点原地跳转)。
- **视觉标识**:http(s) 外链追加 `class="ext-link"`;markdown.css:
  ```css
  .markdown-body a.ext-link::after {
    content: "↗"; font-size: 0.75em; margin-left: 2px;
    color: var(--text-3); transition: color var(--transition);
    display: inline-block; transform: translateY(-0.35em);
  }
  .markdown-body a.ext-link:hover::after { color: var(--brand); }
  ```
  箭头用文字字符(编辑部风,与 mono meta 同源),上移对齐 x-height 顶部;hover 才变 brand,平时 text-3 不抢正文。
- 打印样式:外链已有 URL 落款(main.css),`::after` 箭头在 print 里隐藏。

### 4.3 图片 CLS 防护(如实取舍)

- **详情页封面**(PostDetailView `.post-cover`):容器改 `aspect-ratio: 16/9` + `max-height: 430px` + 内部 img `object-fit: cover; width: 100%; height: 100%`——加载前后容器高度恒定,零抖动。竖图不再被 max-height 剪裁成「半张脸」(现状 object-fit 默认 fill 拉伸/或空白),统一 cover 裁切,构图居中。
- **正文图片**:markdown 管线无原始尺寸数据(服务端 UploadItem 契约无宽高字段),不做伪占位。采用:img 现有 lazy 基础上加 `decoding="async"`;CSS 补 `.markdown-body img { background: var(--surface-2); }`(加载中灰底,与 --code-bg 纸面语言一致)+ 既有加载淡入。CLS 在正文长图场景仍存在,如实记录为已知取舍——修复需后端契约加宽高字段,超出本轮纯前端范围。
- 行内小图不受影响(仅背景色,无布局属性)。

## 5. 列表页精修均衡(V22)

原则:**不推翻 hairline 行列表范式**,只补「hover 有回应、层级有深浅、封面有呼吸」三件事,与 ArticleCard/归档时间轴同语言。

### 5.1 分类页 CategoriesView(`.cat-card`)

- 行 hover:背景 `var(--surface)` + `border-radius: var(--radius-sm)` + 右侧「N 篇」计数变 `--brand`;描述行 text-3 不变(hover 时仅一处色变,克制)。
- 行加水平 padding(-margin 外扩保持现有列对齐),让底色有呼吸不贴字。

### 5.2 标签页 TagsView

- 标签 hover:`--surface` 圆角底(`--radius-sm` + 4px 8px 内边距的视觉等效,用 padding+负 margin 实现不改变行高)、文字变 `--brand`;sup 计数保持 text-3。
- 触屏端 hover 不存在,样式自然无效,无副作用。

### 5.3 友链页 LinksView(`.link-card`)

- 行 hover:背景 `var(--surface)` + logo `transform: scale(1.06)`(与封面 scale 语言同族)+ 名称下划线生长(与页脚 footer-link 同语言:background-size 0→100%)。
- 描述行兜底文案颜色保持 text-3。

### 5.4 专题页 SeriesView / SeriesDetailView

- SeriesView 行 hover:背景 `var(--surface)` + 64px 缩略图 scale(1.05);无封面时首字符占位块同 hover。
- SeriesDetailView 文章行已复用 ArticleCard(自动继承既有 hover),仅核对补齐。

### 5.5 hover 语言全站对账(一次性)

全站可点击行统一为:背景 --surface 浮起(列表行)/ 色变(链接)/ 位移(scale 或箭头)三件套之一,禁止发明第四种。本轮核对:分类/标签/友链/专题四处落地即闭环。

## 6. 状态与评论工艺(V23)

### 6.1 空态统一(EmptyState compact 变体)

- EmptyState.vue 增 `size?: 'default' | 'compact'` prop(default 现状不变):compact 不渲染 SVG 插画,仅 `— <title> —` 式单行居中(mono 可选),padding 32px 16px,颜色 text-3。

### 6.3 评论形态统一(CommentItem)

### 6.4 移动端两处补齐

- **移动菜单遮罩**(SiteHeader `.mobile-panel`):展开时加全屏半透明遮罩(rgba 墨色 0.4)+ 点击遮罩关闭 + body 滚动锁(与 TOC 抽屉同机制);同时修复面板底部双 hairline(最后一项 border-bottom 与面板 border-bottom 重叠)。

## 7. 系统一致性扫荡(V24)

### 7.1 --fs 字号 token 校准(口径收敛)

- 口径:**仅 main.css 与 common/layout 组件内**,与刻度值偏差 ≤0.5px 的硬编码字号归位到 token(如 13.5→var(--fs-sm) 13px、12.5→var(--fs-xs) 12px);views 内部与 markdown.css 的阅读排版字号(有独立刻度逻辑)不动。1px 内差异不可感知,收益是后续调刻度有一处总闸。
- 全量机械替换不做(diff 噪音大、回归风险高,如实记录)。

### 7.2 --header-offset 被 JS 消费

- PostToc.vue(61/88 行)、PostDetailView.vue(357 行)硬编码 76/96px 改为 `parseFloat(getComputedStyle(document.documentElement).getPropertyValue('--header-offset'))`(模块内小工具函数,含 parseInt 兜底 76)。移动端 TOC 抽屉如另有偏移常量一并核对。

### 7.3 页级滚动条定制(与代码块对齐)

- main.css 增加 `html::-webkit-scrollbar`(8px,thumb `--border-strong` 胶囊,track 透明,hover `--text-3`)——与 markdown.css 代码块滚动条完全同值;Firefox 已有 scrollbar-width: thin 不动。

### 7.4 翻页行为统一(usePagedList 单点)

- usePagedList 增加可选 `onPageChange` 回调挂点:翻页后 `window.scrollTo({ top: 0, behavior: 'smooth' })`(reduced-motion 时 auto)。
- CategoryPostsView / TagPostsView 接入回顶 + URL `?page=` 同步(与 HomeView 行为一致);SearchView 接入回顶(URL 仍以 k 为主键,page 参数补齐)。
- HomeView 已有行为,核对不改。

### 7.5 死代码与残留清理

- 删除 `components/common/SearchBox.vue`(全站无引用)。
- 清理 HomeView/PostDetailView 的 `class="chip cat"` 中无样式定义的 `.cat`(类名移除,chip 保留)。
- SiteHeader 移动菜单双 hairline 修复(见 §6.4,若 V23 已做则此处仅核对)。
