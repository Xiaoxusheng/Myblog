> 版本:v3.0 · 对应改版轮次 V12–V16 · 日期:2026-09-20
> 前置:docs/05-前台UI改版二期设计规范.md(V7–V11 静奢编辑风)已完成并通过验收,本轮在其基础上做**三期精修**,不推倒重来。

## 0. 一句话定位

二期解决了「好看」(衬线、颗粒、报头、页脚),三期解决「专业产品感」:**键盘优先的命令面板(⌘K)、正文排版工艺、阅读完成度细节、归档与列表的扫描性**。让站点从「设计过的博客」升级为「有工程与编辑双重打磨的内容产品」。

## 2. 改 vs 不改

**改**:header 搜索入口(触发按钮化)、新增命令面板组件、markdown.css 工艺层、文章详情文末/上下篇/评论区细节、归档页时间轴、标签/分类/友链计数与 hairline 统一、少量全局通用类(kbd)。

## 4. 命令面板(Command Palette,V12 旗舰件)

### 4.1 触发方式

| 入口 | 行为 |
|---|---|
| 桌面 header 搜索按钮 | 点击打开(外观仍是「搜索框形态的按钮」,见 §5) |
| 移动端菜单内搜索按钮 | 点击打开,面板全屏化 |
| 全局快捷键 `Ctrl/⌘ + K` | 任意时刻切换(输入框聚焦时同样生效) |
| `Esc` | 关闭,焦点还原到触发元素 |

### 4.2 键盘交互

- `↑ / ↓`:在扁平结果数组内循环移动,循环不越界。
- `Enter`:跳转当前项(RouterLink push + 关闭面板)。
- 打开时输入框自动聚焦;路由跳转后面板关闭。
- 面板打开期间 `body` 滚动锁定;`role="dialog"` `aria-modal="true"`,结果列表 `role="listbox"` + `aria-activedescendant` 同步。

### 4.3 数据与状态

- 输入 ≥1 字符:防抖 250ms 调 `fetchPosts({ page: 1, pageSize: 8, keyword }, signal)`,`AbortController` 取消上一次请求。
- 空关键词(初始态):显示**快捷导航组**——首页 / 归档 / 分类 / 标签 / 专题 / 友链,mono 编号 + 名称,复用现有路由。
- 无结果态:一句说明 + 「在搜索页查看“关键词”→」链接(保留 /search 兜底)。
- Loading 态:结果区 2 行骨架(复用 `.skeleton`),不做整屏遮罩。

### 4.4 视觉规格

| 项 | 规格 |
|---|---|
| 弹层 | 桌面:`top: 14vh` 居中,max-width 560px;移动:`inset 0` 全屏,输入区 sticky |
| 容器 | `--surface` 背景、1px `--border`、`--radius-lg`、`--shadow-md`,无渐变无发光 |
| 遮罩 | `rgba(黑,0.32)`(dark 0.5)+ `backdrop-filter: blur(4px)`,点击遮罩关闭 |
| 输入区 | 高 52px,无边框,底部 1px `--border`;左侧放大镜 16px `--text-3`;右侧 `Esc` kbd 徽标 |
| 结果行 | 高 48px,标题 14px `--text-1`,meta(mono 12px `--text-3`:日期 · 分类);选中态 `--surface-2` 背景 + 左侧 2px accent 竖线(与 TOC active 同语言) |
| 分组头 | kicker 语言(mono 11.5px 大写间距),如「文章」「快捷导航」 |
| 层级 | z-index 1050(header 之上、Toast/Lightbox 1100 之下);grain 颗粒覆盖其上,质感统一 |
| 进出场 | 进:opacity + translateY(6px) 0.18s ease-out;出:opacity 0.12s;`prefers-reduced-motion` 全局已兜底 |

### 4.5 kbd 通用类(全局新增)

`.kbd`:mono 11px、padding 1px 5px、1px `--border-strong` + 底边 2px、radius 4px、`--surface-2` 底、`--text-3` 色。header 徽标(`⌘K` / `Ctrl K` 按平台检测)、面板输入区 `Esc`、V13 正文 kbd 共用。

## 5. header 搜索入口改造(V12)

- 桌面:删除内联 `SearchBox` 表单,替换为 `.search-trigger` 按钮——放大镜 + 「搜索…」占位文字 + 右侧 `.kbd` 徽标;外观延续原搜索框(34px 高、`--surface-2` 底、radius 8px、focus-within 边框),但语义为 button(`aria-label="打开搜索"`、`aria-haspopup="dialog"`)。
- 移动端菜单:同样替换为全宽 `.search-trigger`(无 kbd 徽标,触屏无快捷键)。
- `/search` 页与 `SearchBox` 组件**保留不删**(搜索页输入框仍用),命令面板是「快搜」而非替代。

## 6. 正文排版工艺 v2(V13,markdown.css)

1. **正文链接工艺**(本轮重点):由「纯色 + hover 下划线」升级为常驻软下划线——`text-decoration: underline; text-decoration-color: var(--brand-soft-border); text-decoration-thickness: 1px; text-underline-offset: 3px`;hover 时 `decoration-color` 过渡为 `var(--brand)`。克制不加外链图标。
2. **kbd / mark / del**:kbd 复用 `.kbd`;`mark` 用 `--brand-soft` 底 + 继承文字色,padding 0 2px;`del` 维持默认灰度。
3. **任务列表**:`li` 含 checkbox 时去列表符,checkbox `accent-color: var(--brand)`,与文字基线对齐。
4. **表格精修**:thead th 用 mono 12.5px `--text-3` + letter-spacing 0.04em(编辑部表头);全部表格单元格 `font-variant-numeric: tabular-nums`。
5. **代码块触屏修复**:现有复制按钮 hover 才显,触屏(`hover: none`)无法触达——`@media (hover: none)` 时 `opacity: 1` 常显、缩小 padding。
6. **图片 hover**:边框色由 `--border` 过渡到 `--border-strong`(配合已有 zoom-in 光标)。
7. 不新增 markdown-it 插件、不改渲染管线(脚注等涉及数据侧,越红线,不做)。

## 7. 阅读体验 v2(V14)

1. **文末结束符**:正文最后一页与「上下篇」之间插入 `.post-end`——居中 mono 12px `--text-3`「· · ·」+ 上下 24px 留白(刊物「完」标记,克制版)。
2. **上下篇(Prev/Next)**:统一为两栏 hairline 分组,标题 15px,方向文字(上一篇/下一篇)kicker 语言;hover 标题变 accent。
3. **相关阅读**:标题行加 kicker;`related-meta` mono 与详情 meta 同语言。
4. **评论区头部**:「评论 N」标题层级与 kicker 统一;评论表单聚焦态边框走 `--border-strong`(已有则核对)。
5. **TOC 平滑滚动**:点击锚点 `scrollIntoView({ behavior: 'smooth' })`(`prefers-reduced-motion` 下自动退化为瞬时,全局 CSS 已兜底)。
6. **详情 meta 行**:`.post-meta` 加 `font-variant-numeric: tabular-nums`。

## 8. 归档与列表工艺(V15)

1. **归档粘性年份**:桌面端 `.year-title` sticky(top = header-offset + 12px,背景 `--bg` 渐变遮罩下沿 hairline);移动端不粘性。
2. **时间轴对齐**:`.tl-date` mono 固定宽 + `tabular-nums`,与标题基线对齐;行 hover 日期变 accent、标题变 `--text-1`(无底色,保持编辑部)。
3. **计数 mono 统一**:归档 `year-count`、分类/标签页计数、专题计数全部 mono + tabular-nums(逐页核对)。
4. **友链页**:保持现有结构,行/卡 hover 统一 hairline 语言;空态文案核对。
5. **首页侧栏**:热门阅读 mono 编号与移动端 `hot-rank` 语言对齐;Sidebar 各块间距核对 8px 网格。

2. 正文工艺:长文阅读 10 分钟不累;链接/kbd/表格在双主题下对比度达标。
3. 触屏:代码块复制按钮可触达;面板结果行触控目标 ≥ 44px。
4. 无模板感红线复查:无渐变堆砌、无大投影、accent ≈ 5% 不变。
5. 375px 无横向滚动;`npm run build` 零错误;功能回归:导航/搜索页/分页/主题切换/评论/TOC/点赞正常。
