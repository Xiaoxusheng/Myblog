## 0. 一句话定位

一期解决「编辑部式骨架」,二期解决「好看」(衬线/颗粒/报头),三期解决「专业产品感」(⌘K/正文工艺/扫描性)。四期是**质感收官**:把仅剩的三处「默认感」彻底消除——语法高亮还是 GitHub 默认色(与全站暖纸墨水语言脱节)、主题切换是生硬的瞬变、目录没有阅读进度感。让每个像素都像「定过的」,而不是「框架给的」。

## 2. 改 vs 不改

**改**:markdown.css 语法高亮配色(--hl-* 全量换 Flexoki)、代码块选区/滚动条工艺、ThemeToggle 动效层(新增 View Transitions 包装,不改 store)、全局按压反馈类、nav hover 态、列表行 meta hover 态、PostToc 进度轨、新增 @media print 层。

## 4. 语法高亮 Flexoki 化(V17,markdown.css)

### 4.1 配色映射原则

结构用墨(标点/注释 = 暖灰),语义用色(关键字/字符串/数字/函数 = 低饱和四色),与正文「墨色三级 + accent」的用色哲学同构。光源 tones:浅色取 Flexoki 600/700(纸底对比度 ≥4.5:1),深色取 400(暗底)。

## 6. 微交互工艺(V18)

### 6.1 主题切换圆形扩散(V18 旗舰件,渐进增强)

- **触发**:ThemeToggle 点击时,若 `document.startViewTransition` 存在且 `matchMedia('(prefers-reduced-motion: reduce)')` 为否——走圆形扩散;否则直接 `theme.cycle()`(不支持的环境静默降级,行为与现状一致)。
- **实现**(ThemeToggle.vue 内新增,不改 theme store):
  ```ts
  function onToggle(e: MouseEvent): void {
    const doc = document as Document & {
      startViewTransition?: (cb: () => void) => { ready: Promise<void> }
    }
    const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches
    if (!doc.startViewTransition || reduce) {
      theme.cycle()
      return
    }
    const rect = (e.currentTarget as HTMLElement).getBoundingClientRect()
    const x = rect.left + rect.width / 2
    const y = rect.top + rect.height / 2
    const radius = Math.hypot(Math.max(x, window.innerWidth - x), Math.max(y, window.innerHeight - y))
    const transition = doc.startViewTransition(() => theme.cycle())
    void transition.ready.then(() => {
      document.documentElement.animate(
        { clipPath: [`circle(0px at ${x}px ${y}px)`, `circle(${radius}px at ${x}px ${y}px)`] },
        { duration: 450, easing: 'cubic-bezier(0.25, 1, 0.5, 1)', pseudoElement: '::view-transition-new(root)' }
      )
    }).catch(() => { /* ready 被跳过时静默 */ })
  }
  ```
- **CSS**(main.css 新增):
  ```css
  ::view-transition-old(root),
  ::view-transition-new(root) { animation: none; mix-blend-mode: normal; }
  ```
- 圆心取按钮几何中心(键盘 Enter 激活同样有正确圆心);radius 取到四角最大距离,保证全屏覆盖。
- grain 层(z-index 1100 fixed)在 VT 快照内,无需处理。

### 6.2 按压反馈(main.css 全局)

```css
.btn:active:not(:disabled),
.icon-btn:active,
.search-trigger:active { transform: scale(0.96); }
```
`.btn/.icon-btn/.search-trigger` 增加 `transition: ... transform`(追加到现有 transition 列表);like-btn 自有动效不参与。scale 幅度 0.96——按下去有物理感,松开即回。

### 6.3 导航 hover 态(SiteHeader.vue)

nav-link hover 增加下划线:2px、`--border-strong`(墨色,非 brand,active 才是 brand),`::after` 现有规则扩展为 hover/active 两态;transition 含 transform/width。active 行为不变。

### 6.4 列表行 meta hover 态(ArticleCard.vue)

`.post-row:hover .meta-date { color: var(--brand) }`——与归档时间轴「hover 日期变 accent」同一语言,首页/搜索列表对齐。

## 7. 阅读工艺 v3(V19)

### 7.1 TOC 进度轨(PostToc.vue)

- 现状:每项自带 `border-left: 2px transparent / active accent`——是「当前位置」语言,没有「读到哪里」。
- 升级:列表容器相对定位,`::before` 画 2px 连续灰轨(top 4px → bottom 4px,`--border`);新增 `.toc-rail` accent 段(2px,`--brand`),`top/height` 由 JS 按当前 active 链接的 `offsetTop/offsetHeight` 计算(从首项顶部到 active 项底部),`transition: top .25s var(--ease-out-quart), height .25s`。
- 各项 `border-left` 移除,层级缩进保留;active 文字色/字重不变。
- 滚动时 rAF 节流机制不变,只追加几何计算。

### 7.2 打印样式(main.css 新增 @media print)

- **隐藏 chrome**:`.site-header、.site-footer、.page-aside、.post-toc-aside、.comment-section、.like-btn、.toc-toggle、.reading-progress、.backtop、.post-end、ReadingProgress、Pagination、MobileDiscover、search-trigger 等`——只留标题/meta/封面/正文/标签/上下篇文字。
- **黑白化**:body 背景 #fff、文字 #111;`:root { --hl-*: 全部收敛为 #333/#666 两级 }`(变量层一份覆盖,高亮区自动变灰阶)。
- **链接落款**:正文外链 `a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 0.85em; color: #666 }`;站内锚点不落款。
- **分页保护**:`h2/h3 { break-after: avoid }`、`pre/table/blockquote { break-inside: avoid }`、`a { text-decoration-color: #999 }`。
- 排版:markdown-body 字号 11.5pt,行高 1.7,阅读列宽 100%。
